# Yesterdays

A Django web application for georeferencing historical images.

[Check out the live site](https://yesterdays.maprva.org), or [read our documentation](https://docs.yesterdays.maprva.org/).

## Development

Please see our documentation pages for [developing](https://docs.yesterdays.maprva.org/development/) and [deploying](https://docs.yesterdays.maprva.org/administration/deployment/) Yesterdays.
