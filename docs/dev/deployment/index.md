# Deploying Yesterdays

If you would like to run your own instance of Yesterdays, we encourage you to get in touch.
We'd be glad to support your efforts!

!!! warning "This is a serious endeavor"

    Yesterdays has become a rather complex system.
    Deploying your own instance of Yesterdays means taking on systems administration responsibilities.

    [Get in touch with us](/contact/), we are eagerly building a community and we want you to help shape it with us.

This section documents [how to deploy Yesterdays onto a Kubernetes cluster](helm-chart.md).
